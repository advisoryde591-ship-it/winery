# 🍷 המרתף שלי

אפליקציה לאייפון לניהול מלאי יין ושמפניות. מצלמים בקבוק, וה-AI (Claude) מזהה אותו ומחזיר:

- **מה זה**: יצרן, שם, בציר, אזור, זנים
- **כמה הוא שווה**: טווח מחירים עדכני (עם חיפוש ברשת)
- **איך הוא טועם**: תיאור טעמים, ארומות, פרופיל (גוף, חומציות, טאנינים, מתיקות)
- **מתי לשתות**: חלון שתייה ושנת שיא, טמפרטורת הגשה ודקנטציה
- **ליד מה**: התאמות אוכל

## מה יש באפליקציה

| מסך | מה עושים בו |
|---|---|
| 🍷 מרתף | כל הבקבוקים, שווי כולל, מיון לפי "מה דחוף לשתות", כפתורי +/− לכמות |
| 📷 הוספה | צילום תווית קדמית (ואחורית אם רוצים) ← זיהוי אוטומטי ← עריכה ושמירה |
| 🤖 מה לשתות | סומלייה אישי שמכיר את המרתף שלכם: "מה לפתוח ליד סטייק?", "מה עומד לעבור את השיא?" |
| 🛒 קניות | בקבוק שנגמר נכנס לכאן אוטומטית. הזמנה בלחיצה אחת בוואטסאפ או במייל לחנות שלכם |
| ⚙️ הגדרות | מפתח API, מטבע, פרטי החנות, גיבוי ושחזור |

בכל כרטיס יין יש גם כפתור **"איפה לקנות ובכמה"** שמחפש ברשת חנויות ומחירים עדכניים.

## התקנה על האייפון

1. **מפעילים את האתר** (פעם אחת): ב-GitHub ← Settings ← Pages ← Source: **GitHub Actions**. אחרי מיזוג ל-`main` האתר יעלה בכתובת
   `https://advisoryde591-ship-it.github.io/winery/`
2. פותחים את הכתובת ב-**Safari** באייפון ← כפתור השיתוף ← **"הוסף למסך הבית"**. מעכשיו זו אפליקציה עם אייקון משלה, במסך מלא.
3. במסך **הגדרות** מדביקים מפתח Claude API (יוצרים אותו ב-[console.anthropic.com](https://console.anthropic.com)) ושומרים.
4. ממלאים את הוואטסאפ/מייל של חנות היין שלכם כדי שההזמנות יגיעו אליה.

## פרטיות ועלויות

- כל המידע (יינות, תמונות, מפתח ה-API) נשמר **רק במכשיר שלכם**. אין שרת.
- כדאי לעשות **ייצוא גיבוי** מדי פעם מההגדרות. מחיקת נתוני Safari מוחקת גם את המרתף.
- כל זיהוי בקבוק עולה בערך כמה סנטים בחשבון ה-API (קצת יותר כשחיפוש המחירים ברשת פעיל).
- השווי והחלון הם הערכה של AI. בבקבוקים יקרים שווה לבדוק גם מול מקור נוסף.

## טכני

PWA סטטי (HTML/CSS/JS ללא build). נתונים ב-IndexedDB. ה-AI הוא Claude (`claude-opus-5-5`) דרך ה-SDK הרשמי `@anthropic-ai/sdk`, עם חיפוש ברשת (`web_search`) לבדיקת מחירים ו-fallback אוטומטי בצד השרת.

הרצה מקומית: `python3 -m http.server 8000` ← http://localhost:8000
